1. Project Overview & Problem Statement

Course: EC2201 Digital Systems
Project Title: Flip-Flop Based Attendance Token Generator

Problem Statement: In traditional manual attendance systems and basic electronic loggers, token generation can suffer from race conditions, unsynchronized states, duplicate attendance marking, and inconsistent identification. In digital engineering, synchronous sequential logic guarantees glitch-free deterministic state progression dictated by a master clock line.

Objective: To engineer and simulate a real-world attendance token generator modeled strictly on digital hardware principles—specifically a 4-bit synchronous binary up-counter built from flip-flops—while demonstrating fault detection, duplicate suppression, and cycle handling.

Proposed Solution: A software simulation where student check-ins act as clock pulses. A digital 4-bit counter ($Q_3 Q_2 Q_1 Q_0$) increments on each valid check-in, assigning a structured attendance token ($ATT\text{-}XXX$) mapped directly to the hardware counter state. Global record persistence ($REC\text{-}XXX$) is cleanly decoupled from the 16-state modulo digital counter.

2. 4-Bit Synchronous Counter & Flip-Flop Concepts

A flip-flop is a bistable multivibrator capable of storing 1 bit of memory. A 4-bit binary counter utilizes 4 flip-flops ($Q_3, Q_2, Q_1, Q_0$) to count from $0000_2$ ($0_{10}$) through $1111_2$ ($15_{10}$) and wraps modulo-16 back to $0000_2$.

T-Flip-Flop Excitation Logic

In a T-flip-flop, the next state is given by the characteristic equation $Q^+ = Q \oplus T$. For a synchronous binary up-counter:

T0 = 1                               [Q0 toggles on every active clock pulse]
T1 = Q0                              [Q1 toggles when Q0 is 1]
T2 = Q1 AND Q0                      [Q2 toggles when lower bits are all 1]
T3 = Q2 AND Q1 AND Q0               [Q3 toggles when Q2, Q1, Q0 are all 1]
D-Flip-Flop Equivalent Next-State Logic

In a D-flip-flop, the input $D$ directly dictates the next state ($Q^+ = D$). The equivalent D inputs implementing the same synchronous counter are:

D0 = NOT Q0
D1 = Q1 XOR Q0
D2 = Q2 XOR (Q1 AND Q0)
D3 = Q3 XOR (Q2 AND Q1 AND Q0)

3. Token Generation, Duplicate Prevention & Cycle Architecture

  • Token Generation: Tokens represent the current 4-bit counter decimal value zero-padded to 3 digits (e.g., $0001 \to ATT\text{-}001$, $1111 \to ATT\text{-}015$). When the counter wraps $1111 \to 0000$, it generates $ATT\text{-}000$ in the next cycle.
  • Decoupled Record Uniqueness: While the 4-bit hardware counter cycles through 16 states ($0000 \dots 1111$), every attendance record is assigned an invariant sequential Record ID ($REC\text{-}001, REC\text{-}002, \dots$). Record IDs are never reset or reused during normal operation.
  • Duplicate Student Attendance Prevention: If a student attempts to record attendance again in the active session, the system flags DUPLICATE_STUDENT_ATTENDANCE. The request is rejected, the digital counter does NOT advance, no token is issued, and the fault is recorded in the system audit log.
  • Reset Behavior: Triggering Reset Counter zeroes the flip-flops ($Q_3 Q_2 Q_1 Q_0 \to 0000$), sets decimal to $0$, increments the session Cycle count, and writes a RESET event to the audit log. Crucially, previous attendance records are preserved.
  • Counter Overflow Handling: When the counter reaches $1111_2$ ($15_{10}$) and receives the next pulse, it overflows to $0000_2$. The system automatically increments the Cycle count ($Cycle\ 1 \to Cycle\ 2$), logs COUNTER_OVERFLOW, and continues operation without data collision.

The concepts demonstrated here form the foundation of numerous real-world digital engineering systems:

  • Smart Campus Access & Turnstiles: Hardware token generators controlling physical turnstile access based on synchronous counters and RFID pulses.
  • Queue Management Systems: Bank and hospital counter ticket dispensers driven by sequential digital logic.
  • Factory Assembly Line Trackers: Conveyor belt item counters using optical interrupt sensors as clock inputs to flip-flop registers.
