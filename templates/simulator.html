How Flip-Flops Change State

In this synchronous 4-bit counter, all four flip-flops receive the clock pulse simultaneously. The state transition behavior follows exact digital logic rules:

  • Q0 toggles on every single clock pulse because its toggle input is tied to constant HIGH (\(T_0 = 1\)).
  • Q1 toggles only when \(Q_0 = 1\) (\(T_1 = Q_0\)), producing the standard binary counting frequency division by 2.
  • Q2 toggles only when both \(Q_0 = 1\) AND \(Q_1 = 1\) (\(T_2 = Q_1 \cdot Q_0\)), signaling a carry into bit 2.
  • Q3 toggles only when \(Q_0, Q_1,\) and \(Q_2\) are all 1 (\(T_3 = Q_2 \cdot Q_1 \cdot Q_0\)), signaling a carry into MSB.
  • When state reaches 1111 (15), all toggle inputs are 1, so on the next clock pulse all four flip-flops toggle back to 0000 (0), completing one full 16-state cycle.
